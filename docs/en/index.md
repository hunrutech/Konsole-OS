# Konsole OS Documentation

Welcome to the documentation hub for **Konsole OS**, an Android terminal app with a Termux-compatible Linux userspace, a launcher-style dashboard, and optional automation tools.

## Choose a guide

- [README and Quickstart](../../README.md) — project overview, prerequisites, and first local build.
- [User Guide](../USER_GUIDE.md) — installation, terminal workflows, dashboard, packages, settings, macros, and troubleshooting.
- [Developer Guide](../DEVELOPER_GUIDE.md) — architecture, modules, configuration schemas, Android integrations, build/CI, and contribution workflow.
- [Security Policy](../../SECURITY.md) — vulnerability reporting guidance.
- [License](../../LICENSE.md) — project license and third-party exceptions.

## Visual reference

The User Guide includes screenshots of the terminal, dashboard, installed-app drawer, command palette, Macro Lab, and macro editor. The screenshots are illustrative captures and may not exactly match every current build.

## Project notes

This repository contains the Android application and its reusable terminal modules. It does not provide a server-side API or database. See the Developer Guide for Android intent integrations and local storage formats.
